## 一、协议范围与关系说明

1.1 本应用是由学生团队开发的第三方校园工具，**不是安徽大学官方应用**，与安徽大学及其下属单位、学习通平台不存在隶属、代理、合作或授权关系。

1.2 你使用本应用访问的校园服务，仍应遵守学校及相关平台的规章制度、用户协议与收费标准。本协议不影响你与学校之间的法律关系。

## 二、服务内容

2.1 本应用提供校园信息查询、日程管理、提醒、AI 对话与工具调用等功能。具体功能以你安装的版本为准。

2.2 本应用的部分能力依赖第三方服务，包括学校系统、学习通与你自行配置的大语言模型服务。第三方服务的中断、变更、限流或收费调整，可能导致相应功能不可用。

2.3 本应用目前免费提供。我们保留在未来就部分功能收费或调整服务范围的权利，调整前会在应用内说明。

## 三、账号与安全

3.1 你应使用本人合法持有的智慧安大账号登录。**不得使用他人账号，不得出借、转让或共享账号。**

3.2 你应妥善保管账号密码、学习通会话与模型 API Key。因你保管不善、设备丢失或被他人使用造成的损失，由你自行承担。

3.3 你知悉：本应用的登录凭据与密钥仅保存在本机。卸载应用、清除数据或更换设备后，需要重新登录与配置。

3.4 你发现账号异常、设备丢失或密钥泄露时，应立即修改学校账号密码、清除应用数据，并通过本协议末尾的方式通知我们。

3.5 本应用提供的会话保持、静默重登仅用于提升体验，不构成对账号安全的保证。你应自行承担因设备被他人使用产生的风险。

1. 未经授权访问、扫描、探测或干扰学校系统及其他第三方系统；

5.1 本应用的对话与工具编排由大语言模型驱动。**AI 生成的内容可能存在错误、遗漏、过时或与学校实际安排不一致的情况，不构成学校官方通知或专业意见。**

6.1 本应用展示的余额、账单、电费等信息来自学校系统，可能存在延迟，最终以学校系统为准。

6.2 付款码、充值等操作均在对应页面由你本人确认后提交。**支付密码只在本地确认框中输入，不会进入对话记录，不会发送给模型，也不会保存到磁盘。**
