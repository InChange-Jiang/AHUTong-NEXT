## 引言

安大通NEXT（以下简称“本应用”）是由安大通NEXT开发团队（以下简称“我们”）开发并维护的校园服务应用。我们按照**合法、正当、必要和诚信**的原则处理个人信息，并依据《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》《中华人民共和国数据安全法》等法律法规制定本政策。

本政策说明你使用安大通NEXT Android 客户端时，个人信息的收集与使用、存储与保护、对外提供方式，以及你行使个人信息权利的方法。请在使用前仔细阅读；涉及**敏感个人信息、第三方提供**的内容，请特别关注。

需要特别说明的是：

- **本应用是学生团队开发的第三方工具，不是安徽大学官方应用**，与安徽大学及其下属部门、学习通平台不存在隶属、代理或合作关系。你使用校园服务时，仍应遵守学校及相关平台的规定。
- 本应用的服务依赖**安徽大学各官方业务系统**（统一身份认证、教务系统、一卡通系统、智慧安大平台、失物招领平台等）。你使用相关功能时，将以本人账号向学校系统发起登录与查询请求，学校系统按其自身规则处理数据，本应用不代替学校作出承诺。
- 本应用的部分功能依赖**学习通（超星）**。该平台是独立于安徽大学的商业服务，其账号体系与数据处理规则由超星平台负责。
- 本应用部分能力依赖你自行配置的**第三方大语言模型服务**。模型服务商由你选择，其处理规则适用其隐私政策。
- 本应用为校园便民工具，**不向你收取任何使用费用**，不含广告，不进行用户画像或个性化推荐投放。

## 一、我们如何收集和使用你的个人信息

**个人信息**是指以电子或者其他方式记录的与已识别或者可识别的自然人有关的各种信息。**敏感个人信息**是指一旦泄露或者非法使用，容易导致自然人的人格尊严受到侵害或者人身、财产安全受到危害的个人信息，包括生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹等信息，以及不满十四周岁未成年人的个人信息。

我们遵循最小必要原则，仅在本政策所述目的所必需的最小范围内收集和使用信息。你拒绝提供某项信息，可能导致对应功能无法使用，但不影响其他功能。

我们处理个人信息的合法性基础包括：

1. **履行合同所必需**：为向你提供登录、查询、对话、提醒等你主动使用的功能；
2. **取得你的同意**：例如通知权限、连接学习通、配置第三方模型、发布失物招领信息；
3. **履行法定义务**：例如配合司法机关或监管部门依法提出的要求；
4. **保护重大合法权益**：在紧急情况下为保护你或他人的生命健康、财产安全所必需。

涉及**敏感个人信息**（如账号密码、校园卡金融账户信息、支付密码）的处理，我们会在你主动发起对应操作时，以登录、确认等方式取得你的单独同意，并采取加密等更严格的保护措施。你可以拒绝，但相应功能将无法使用。

### （一）账号登录与身份验证

为提供课表、成绩、校园卡、作业等校园服务，你需要使用账号登录。登录方式分为两类：

1. **智慧安大统一身份认证（学校）**。你输入学号与密码后，本应用在设备端向安徽大学统一身份认证平台提交认证请求，获取访问教务、一卡通等系统所需的 Cookie 或 Token。登录过程中如遇图形验证码，验证码图片会被上传至我们使用的验证码识别服务（openahu.org）进行识别，识别结果返回后用于完成本次登录；本应用不保存该图片。我们不会将你的学校密码上传至安大通NEXT自有服务器。
2. **学习通账号登录（超星）**。你使用学习通相关功能时，需单独输入学习通账号（手机号）与密码。本应用会将凭据提交至超星学习通登录接口完成登录，并保存其会话 Cookie。该凭据仅用于你主动发起的登录与静默重登。

**登录凭证的本地保存方式**：

- 学校系统的登录凭据（学号、密码）与学校系统下发的 Cookie，使用 **Android Keystore** 保护的密钥加密后保存在应用私有目录，用于会话续期与免重复登录。
- 学习通账号与密码同样经 **Android Keystore** 加密后保存在应用私有目录；学习通会话 Cookie 保存在应用私有目录中。
- 你退出登录或清除应用数据后，上述凭据会被删除。

### （二）校园服务查询（安徽大学校内系统）

完成登录后，为完成你主动发起的查询与操作，本应用会携带你的登录凭证向学校相关系统请求并获取下列数据，在设备本地展示并缓存：

- 学期课表、课程信息、教学班与教师信息；
- 成绩、绩点、排名、培养方案与学分完成情况；
- 考试安排、考场与座位；
- 教务考勤、评教任务；
- 空闲教室、校历；
- 校园卡余额、卡号、账单与消费记录；
- 宿舍电费与充值条件；
- 校园通知、失物招领信息；
- 学生邮箱的文件夹、邮件列表与正文；
- 与你账号关联的学号、姓名、学院、专业、班级、校区等身份信息。

上述数据的所有权归学校或相关服务方所有，本应用仅在本机为你展示与缓存，不将这些数据上传至安大通NEXT自有服务器。

### （三）学习通（超星）服务

连接学习通后，本应用会获取你的课程列表、作业、课程任务与学习进度，用于作业提醒、日程展示和对话查询。作业详情、题目等页面可能通过浏览器或应用内 WebView 打开，此时你的学习通会话 Cookie 会被用于保持登录状态。你在这些页面中的操作由超星平台按其规则处理。

### （四）AI 对话与第三方模型服务

1. 你在对话中输入的文字、为回答问题所必需的工具结果（例如课表片段、成绩、日程、余额等），会发送至你**在设置中选择的模型服务商**（如 DeepSeek，或你自行填写的其他兼容接口），用于生成回复。
2. 对话记录、工具调用结果保存在本机，你可以在“历史对话”中查看、删除或清空。
3. 你配置的模型 API Key 通过 **Android Keystore** 加密保存，不以明文存储，也不会进入对话记录。我们不会将你的 API Key 用于你配置之外的用途。
4. **我们不会将你的对话用于训练模型，也不会把对话上传到安大通NEXT自有服务器。** 模型服务商是否将请求用于其自身目的，取决于你选择的服务商及其政策，请你在选择前阅读相应条款。
5. 若你开启“联网搜索”，相关查询会通过模型服务商的搜索能力发起，搜索内容同样受该服务商规则约束。
6. 涉及校园卡支付密码等敏感信息，本应用只在本地确认框中接收，**不会写入对话记录，不会发送给模型，也不会保存到磁盘**。
7. **自动化决策说明**：本应用使用模型生成回复与工具调用建议，但不基于你的个人信息进行自动化决策以产生法律效果或对你的权益产生重大影响。涉及缴费、删除数据等操作，均需你本人确认后才会执行。你可以不接受 AI 建议，直接使用页面功能完成同样的事情。
8. **跨境提供提示**：你选择的模型服务商可能位于中华人民共和国境外，提问与必要工具结果可能在其所在司法辖区处理。我们不会主动向境外提供你的信息；如你对此有顾虑，请选择境内服务商，或不使用对话功能。

### （五）日程、提醒与自定义课程

你添加的自定义课程、自建日程、提醒与电费房间等，仅保存在本机。开启通知权限后，本应用会在本地安排课程提醒与电费提醒；开机自启权限用于设备重启后恢复本地提醒。上述信息不会上传至我们的服务器。

### （六）校园卡付款码与资金相关操作

1. 付款码由学校一卡通系统签发，本应用在设备端获取并展示，可能在本机短期缓存其令牌以减少重复请求，缓存到期或你刷新后失效。
2. 充值、缴费等操作在对应页面由你本人确认后提交至学校系统。支付密码只在本地确认框中输入，不会进入对话记录、不会发送给模型、不会保存到磁盘。
3. 本应用不代扣、不代付、不托管你的资金，也不保存你的银行卡信息。

### （七）必吃榜聚合统计

“必吃榜”展示的是按时间段、食堂范围聚合后的消费统计结果。为获取榜单，本应用会向开发者维护的统计接口（inchangejiang.cn）发送**查询条件**（如时间范围、食堂名称、最小交易笔数）。该请求**不包含**你的学号、姓名、卡号、账户余额或任何可识别个人身份的信息。统计接口可能按常规服务日志记录请求时间、IP 地址等技术信息，用于安全防护与故障排查，不用于识别你的身份或向你推送内容。

### （八）天气、学习资料与外部内容

- **天气**：本应用使用第三方天气接口（uapis.cn）按城市“合肥”获取天气信息。本应用**不申请定位权限**，不会上传你的位置。
- **学习资料**：资料库通过 GitHub 的公开接口浏览与下载文件，可能记录下载来源与文件地址；本应用不上传你的个人信息。
- **校园通知**：本应用抓取学校公开网站的通知列表与正文，用于展示；抓取对象为公开页面。
- **失物招领**：浏览与发布通过学校失物招领平台完成。你发布的内容（如物品描述、联系方式）会提交至该平台，请谨慎填写。

### （九）设备与日志信息

本应用**未接入**广告、用户行为分析、崩溃上报等第三方 SDK，不收集设备标识符（IMEI、OAID、Android ID 等）、通讯录、短信、通话记录、相册、麦克风或精确位置。为排查故障，应用可能在本地生成技术日志（如网络错误码），这些日志默认不离开设备；如你主动导出并发送给我们，我们仅用于定位问题，处理完毕后删除。

### （十）应用更新

当前版本未启用自动更新检查。未来若启用，更新检查只会向发布渠道请求版本号与更新说明，不会上传你的个人信息。

### （十一）其他说明

1. 我们不会将你的个人信息用于广告投放、用户画像、信用评估或与本应用无关的用途。
2. 我们不会出售你的个人信息。
3. 如我们需要将信息用于本政策未载明的其他目的，会另行征得你的同意。

### 个人信息收集使用一览

- **智慧安大登录**：涉及学号、密码、验证码图片。提交至学校系统认证；验证码图片交 openahu.org 识别；凭据在本机加密保存。
- **学习通登录**：涉及手机号、密码、会话 Cookie。提交至超星学习通；凭据与会话在本机加密保存。
- **校园数据查询**：涉及课表、成绩、考试、考勤、账单、电费、通知、邮件等。仅向学校系统请求，不上传至我们；结果在本机缓存。
- **AI 对话**：涉及提问、必要工具结果、对话记录。发送至你选择的模型服务商；记录在本机保存。
- **模型配置**：涉及 API Key、接口地址、模型名。仅用于你配置的接口；API Key 加密保存。
- **付款码与充值**：涉及付款码令牌、金额、支付密码。付款码与充值请求提交至学校系统；支付密码不离开本机。
- **必吃榜**：涉及时间范围、食堂名称等查询条件。发送至 inchangejiang.cn，不含身份信息，不保存个人信息。
- **天气**：涉及城市名“合肥”。发送至 uapis.cn；结果在本机缓存。
- **学习资料**：涉及浏览路径、下载文件。请求 GitHub 公开接口；文件在本机缓存。
- **日程与提醒**：涉及自建日程、自定义课程、提醒时间。仅在本机处理与保存。
- **失物招领发布**：涉及你填写的物品与联系方式。提交至学校失物招领平台，并在本机缓存。

## 设备权限说明

- **网络访问（INTERNET）**：用于登录学校系统、获取校园数据、调用模型与第三方接口。必须授权，拒绝后无法使用联网功能。
- **通知（POST_NOTIFICATIONS）**：用于课程提醒、电费提醒。可选，拒绝后收不到本地提醒。
- **开机自启（RECEIVE_BOOT_COMPLETED）**：用于设备重启后恢复本地提醒。可选，拒绝后重启可能丢失提醒。
- **应用可见性（queries：com.chaoxing.mobile）**：用于判断是否安装学习通，便于跳转。可选，拒绝后相关跳转可能不可用。

你可以随时在系统设置中关闭上述权限。关闭后不影响已保存数据的查看。

## 二、我们如何使用 Cookie 和同类技术

1. 本应用不使用广告或追踪类 Cookie。你在登录学校系统、学习通或打开其网页时，相关系统会下发会话 Cookie，本应用将其保存在应用私有目录，用于维持登录状态。
2. Cookie 仅用于你主动使用的校园功能，不用于跨应用追踪，不向第三方出售或共享（向你访问的系统本身除外）。
3. 你可以通过退出登录、清除应用数据或卸载应用删除本地 Cookie。删除后需要重新登录。

## 三、我们如何共享、转让、公开披露你的个人信息

### （一）共享

我们不会出售你的个人信息。仅在实现功能所必需时，按以下方式共享：

- **安徽大学相关系统**：共享登录凭据与查询请求，用于完成认证与校园数据查询，由学校按其规则处理。
- **学习通（超星）**：共享学习通账号、密码与会话，用于登录并获取作业数据，由超星按其规则处理。
- **你选择的模型服务商**：共享提问与必要工具结果，用于生成 AI 回复，由你自行选择并受其政策约束。
- **openahu.org**：共享登录验证码图片，仅用于当次识别；本应用不保存该图片。
- **inchangejiang.cn**：共享时间范围、食堂名称等查询条件，用于获取必吃榜聚合统计，不含身份信息。
- **uapis.cn**：共享城市名“合肥”，用于获取天气，不含身份信息。
- **GitHub**：共享资料浏览与下载请求，用于获取公开学习资料，不含身份信息。
- **学校失物招领平台**：共享你填写的发布内容，用于发布失物招领，由学校平台处理。

### （二）第三方 SDK 及服务清单

本应用未集成广告、统计分析、推送、崩溃监控类 SDK。上述第三方服务均通过网络请求直接访问，不嵌入其统计代码。第三方服务可能按其自身政策收集请求日志（如 IP、时间、设备网络类型），我们无法控制其处理行为，建议你在使用前阅读相应隐私政策。

### （三）数据转让

如发生合并、收购、重组或资产转让，涉及个人信息转移的，我们会要求承接方继续受本政策约束，否则将重新征得你的同意。

### （四）公开披露

我们不会公开披露你的个人信息，但以下情形除外：获得你的单独同意；法律法规、司法或行政机关依法要求；为维护你或他人的生命、财产等重大合法权益且难以取得本人同意。

### （五）例外情形

根据法律法规，在下列情形中我们可能无需取得你的同意即可处理信息：为订立、履行你作为一方当事人的合同所必需；为履行法定职责或法定义务所必需；为应对突发公共卫生事件或紧急情况下保护自然人的生命健康、财产安全所必需；在合理范围内处理你自行公开或其他已合法公开的个人信息；法律法规规定的其他情形。

## 四、我们如何存储和保护你的个人信息

### （一）存储地点与期限

1. 除表 1 所列的第三方请求外，你的个人信息保存在**你的设备本地**。我们没有集中存储用户个人信息的数据库。
2. 登录凭据、缓存数据、对话记录会一直保留，直至你在应用内删除、清除数据或卸载应用。
3. 付款码令牌等短期缓存在有效期届满后自动失效。
4. 卸载应用后，本地数据将从设备删除且无法恢复。

### （二）安全保护措施

1. 登录密码、学习通密码与模型 API Key 使用 **Android Keystore** 保护的密钥加密存储。
2. 与支持 HTTPS 的服务通信时使用加密传输；对证书异常或降级连接进行拦截。
3. 支付密码不写入日志、不进入对话、不落盘。
4. 我们限制内部人员接触你的信息；如你主动提供日志，我们仅在定位问题所需范围内使用，并在处理完毕后删除。

**安全提示**：互联网环境不存在绝对安全。个别学校上游服务目前仅支持 HTTP 明文传输，使用相关功能时可能存在被网络中间人观察的残余风险；如你身处公共网络，建议暂缓进行登录、充值等敏感操作。因你自身保管不善、设备丢失或被他人使用导致的损失，需由你自行承担。

### （三）安全事件的处置

1. 如我们发现或被告知发生个人信息泄露、篡改、丢失等安全事件，会立即启动排查，评估影响范围，并采取补救措施。
2. 对可能对你造成较大影响的事件，我们会通过应用内提示、你获取本应用的渠道等方式告知你事件基本情况、可能的影响、我们已采取的措施以及你可以采取的防护建议。
3. 依法需要向监管部门报告的，我们会按规定报告。
4. 由于本应用以本地存储为主，设备丢失、被他人解锁使用是主要风险之一。建议你为手机设置锁屏密码，并在更换设备前退出登录、清除应用数据。

## 五、你如何管理你的个人信息

### （一）查询与更正

你可以在应用内查看账号、课表、成绩、日程、对话记录等信息。校园数据以学校系统为准；如发现错误，请向学校相关部门申请更正。模型配置可在“设置 → 模型与性格”中查看与修改。

### （二）删除

你可以删除单条对话、清空全部聊天记录、删除自建日程与自定义课程，或通过系统设置清除应用数据、卸载应用。删除操作不可撤销。

### （三）撤回同意与关闭功能

你可以关闭通知、开机自启权限，退出学习通或智慧安大登录，关闭联网搜索，或停止使用相关功能。撤回同意不影响此前基于同意已进行的处理。

### （四）注销账号

本应用没有独立的账号体系，你的账号即学校账号。你可以在应用内退出登录，并通过卸载应用清除本地数据；学校账号的注销请按学校规定办理。

### （五）投诉与举报

如你认为个人信息权益受到侵害，可通过本政策末尾的方式联系我们；我们会在收到请求后 15 个工作日内答复。你也可以向网信、市场监管等主管部门投诉或依法提起诉讼。

### （六）请求的处理

1. 为保障安全，我们可能先核验你的身份（例如确认你能够控制对应学校账号或设备），再处理你的请求。
2. 对于合理的请求，我们原则上不收取费用；对重复、超出合理限度或需要过多技术手段的请求，我们可能收取合理成本或说明无法处理的原因。
3. 在下列情形中，我们可能无法响应你的请求：与国家安全、国防安全直接相关；与公共安全、公共卫生、重大公共利益直接相关；与刑事侦查、起诉、审判和判决执行等直接相关；有充分证据表明你存在恶意或滥用权利行为；为履行法律法规规定的义务所必需。
4. 你注销或删除数据后，我们可能仍需按照法律法规要求保留必要的记录；超出保留期限后，我们会删除或匿名化处理。

## 六、未成年人保护

本应用面向高校在校学生。若你未满 18 周岁，请在监护人陪同下阅读本政策，并在取得监护人同意后使用。我们不会主动收集未成年人的个人信息；如你是监护人，发现未成年人未经同意使用本应用，可联系我们协助删除相关数据。

## 七、本政策如何更新

我们可能因功能调整或法律法规变化更新本政策。更新后，我们会在应用内以显著方式提示，并更新本页面的版本号与生效日期。若更新导致你的权利发生实质性变化，我们会再次征得你的同意。你继续使用本应用，视为接受更新后的政策。

## 八、如何联系我们

如你对本政策或个人信息处理有任何疑问、意见或投诉，可通过你获取本应用的渠道（如项目仓库、内测群）与我们联系。为保障安全，我们可能需要先验证你的身份，再处理相关请求。

## 九、定义与附则

### （一）定义

- **个人信息**：以电子或者其他方式记录的与已识别或者可识别的自然人有关的各种信息，不包括匿名化处理后的信息。
- **敏感个人信息**：一旦泄露或者非法使用，容易导致自然人的人格尊严受到侵害或者人身、财产安全受到危害的个人信息，包括生物识别、宗教信仰、特定身份、医疗健康、金融账户、行踪轨迹等信息，以及不满十四周岁未成年人的个人信息。
- **去标识化**：个人信息经过处理，使其在不借助额外信息的情况下无法识别特定自然人的过程。
- **匿名化**：个人信息经过处理无法识别特定自然人且不能复原的过程。
- **设备**：你用于安装和使用本应用的手机或其他终端。

### （二）附则

1. 本政策是《安大通NEXT 用户协议》的组成部分，两者不一致时，就个人信息保护事项以本政策为准。
2. 本政策的标题仅为阅读方便，不影响条款含义。
3. 本政策以中文书写，如存在其他语言译本，以中文版本为准。
4. 本政策自生效日期起施行。
